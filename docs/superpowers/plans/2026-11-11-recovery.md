# v1.4 구현·검증 계획

1. Transport: 빈 줄 오인 재현 후 최소 허용, 오류코드/재시도 가능 여부, 단계·수신 관측.
2. Runner: 제한 재접속, 원래 NAT/변경전송 여부 유지, 재조회 후 판단, 메모리 재개.
3. GUI: 자동 복구·미완료 이어하기·로컬 기록, 단계와 시간 표시, 이벤트 갱신 실패 복원.
4. Journal: 원문·비밀값을 제외한 기록, 파일쓰기 실패가 작업을 멈추지 않도록 처리.
5. 실제 로컬 TCP 단절·재접속 통합 검증, GUI 검사, 독립 코드 검토.
6. 문서·검증 범위를 갱신한 뒤 Windows 런타임 포함 EXE/ZIP 재생성, CRC/추출 동일성 검사.
